# OronBox 资源发布协议

版本：1.0.0
生效日期：2026-07-19

## 1. 适用范围

本协议适用于通过 OronBox 官方资源服务上传、审核、公开、更新或向第三方发布资源的用户

## 2. 发布者保证

发布者应使用本人合法控制的 BandBBS 账号

代表团队、组织、雇主、委托方或共同作者提交资源时，应已经取得充分授权

OronBox 可以在存在安全、投诉或权利疑问时，要求发布者提供许可证、授权、素材来源、原始工程、提交历史或其他合理证明

发布者确认对提交的程序、表盘、图片、文字、字体、音频、商标及其他材料拥有必要权利或已经取得许可

发布者不得提交恶意代码、窃取信息的内容、故意损害设备的内容、违法内容或侵犯他人知识产权及其他合法权益的内容

发布者应如实选择 VelaOS 或 Zepp OS、资源类型和支持设备，不得故意隐瞒已知兼容性或安全问题

VelaOS 和 Zepp OS 是两类不同的穿戴设备操作系统及资源平台，其资源不应仅因名称或扩展名相似而被认定为互相兼容

发布者还应保证资源说明、版本、功能、收费属性、更新内容和外部发布信息真实准确，并遵守所使用第三方材料的许可证和署名要求

## 3. 向 OronBox 提供的许可

### 3.1 许可授予

为提供本协议所述服务，发布者在资源服务存续期间授予 OronBox 一项全球范围内、免版税、非独占的许可，允许 OronBox：

- 存储、复制和提供资源下载
- 分析资源平台、类型、包 ID 和版本
- 将图片按原比例缩小并转换为 WebP
- 在资源页面展示名称、说明、作者名称和图片
- 将审核通过的公开文件对象复制到 R2，用于公开分发
- 按发布者的明确选择向米坛或 AstroBox 提交内容

许可还包括为完成服务而进行的必要解包、校验、有效载荷提取、安全检查、格式迁移、备份恢复和发布元数据生成

### 3.2 技术服务商

发布者同意 OronBox 可以将完成服务所必需的权利再许可给提供服务器、对象存储和网络分发的技术服务商，但仅限于实现上述目的，不得将未公开资源用于与服务无关的用途

### 3.3 权利保留

除上述必要授权外，发布者仍保留对资源内容依法享有的权利，本协议不构成资源所有权或著作权的转让

发布者申请下架后，OronBox 会停止新的公开分发，但合理备份、审核记录和第三方已保存的副本可能不会立即消失

## 4. 上传与版本

发布者需要先选择资源平台和类型，再上传至少一张预览图、资源文件并绑定支持设备

OronBox 会根据文件内容识别平台和资源类型，识别结果与用户选择不一致时可以拒绝提交

提交审核后，当前版本形成不可修改的版本存档，后续修改通过新版本完成并重新审核

版本存档包括文字、图片、文件、分析结果、设备绑定及本次选择的外部发布配置

平台和资源类型在创建后固定，不得把既有 VelaOS 资源直接变更为 Zepp OS 资源，反之亦然

同一文件可以绑定多个设备，同一版本也可以包含分别适配不同设备的多个文件

图片宽和高均限制在 1500px 内，超出时保持原比例缩小并统一转换为 WebP

AstroBox icon 必须由用户提供为方形，cover 必须由用户提供为 3:2，OronBox 不会裁切或修正其比例

## 5. OronBox 审核

资源公开前需要按照《OronBox 资源审核规则》审核，审核可以批准、拒绝或要求修改

《OronBox 资源审核规则》是本协议的组成部分，对审核标准、通过或拒绝情形、处置和申诉作出具体规定，发布者提交资源前应当查阅并理解该规则

审核涵盖提交完整性、平台和类型、设备绑定、内容说明、安全与隐私、权利与来源、资源质量及外部发布要求

审核不代表 OronBox 对资源进行完整代码审计，不保证发现所有缺陷，也不构成对资源安全性和兼容性的背书

审核通过后，该版本进入 OronBox 资源目录，并触发用户选择的外部发布任务

发现安全、侵权或违法问题后，OronBox 可以暂停下载、拒绝更新、撤下资源或联系相关第三方平台

## 6. 发布到米坛

米坛发布需要独立的 BandBBS 发布授权，普通登录权限不能用于发布资源

发布者选择目标分区并确认后，OronBox 可以使用该授权上传附件并创建或更新与当前 OronBox 资源关联的米坛资源

米坛发布授权必须属于当前登录所对应的同一个 BandBBS 用户

OronBox 只会在本次确认的资源范围内执行：

- 上传资源文件和必要图片附件
- 设置名称、说明、版本、目标分区和其他必要字段
- 创建新的米坛资源
- 更新此前由同一 OronBox 资源发布并保存关联关系的米坛资源
- 查询并记录发布结果、资源 ID 和外部链接

该授权不会用于发布其他用户或其他资源的内容，也不会提供给插件或无关第三方

米坛资源发布不经过 OronBox 之外的预设审核步骤，但 BandBBS 仍可依据其规则独立管理或删除内容

撤销 BandBBS 授权会停止未来操作，不会自动删除已经发布的米坛资源

## 7. 发布到 AstroBox

当前仅 VelaOS 快应用和 VelaOS 表盘可以选择 AstroBox 发布，Zepp OS 资源不能提交到 AstroBox-Repo

使用自己的 GitHub 账号时，OronBox 可以按用户确认创建或更新资源仓库、Fork AstroBox-Repo、创建分支和 Commit，并提交 Pull Request

相关 GitHub 仓库、Commit、Fork 和 Pull Request 通常是公开记录，并可能显示用户的 GitHub 用户名

OronBox 会执行：

- 创建或更新资源仓库
- 写入资源文件、预览图、icon、cover 和 manifest
- Fork 或同步 AstroBox-Repo
- 创建发布分支和 Commit
- 更新 ABRepo 目录数据
- 向 AstroBox-Repo 提交 Pull Request
- 查询 PR 状态并显示审核结果

路径、文件名、压缩、manifest 排版和设备标识等不改变资源实质内容的机械调整可以自动完成

改变作者署名、资源名称、收费属性、许可证、支持设备、实质说明或替换资源文件时，应重新取得用户确认

AstroBox-Repo 维护者独立审核 Pull Request，OronBox 不保证 PR 被合并，也不代表 AstroBox 对资源作出认可

撤销 GitHub 授权不会自动删除仓库、Commit、Fork、Pull Request 或 AstroBox 历史

## 8. 每次发布确认

每次提交资源版本前，OronBox 应展示本次版本、文件、图片、支持设备、目标平台和执行身份

用户确认本次提交只授权当前显示的操作，不等于授权 OronBox 发布其他内容

确认页面至少应展示：

- 资源名称、版本、平台和类型
- 文件、图片及支持设备绑定
- 是否公开到 OronBox
- 米坛目标分区及将创建或更新的资源
- AstroBox Item ID、标签和付费属性
- 将要创建或更新的仓库及 Pull Request

新增 OAuth 权限、扩大外部操作范围时，需要重新说明并取得确认

## 9. 投诉与下架

权利人或用户可以通过 t3164473115@163.com 提交安全、侵权或违法内容投诉，并提供资源链接、问题说明和必要证明

可以投诉的事项包括：

- 未经授权复制、修改或重新发布作品
- 盗用名称、商标、图片、字体、音乐、代码或其他材料
- 冒充官方、组织、团队或其他创作者
- 未经授权使用姓名、肖像、隐私或个人信息
- 恶意代码、凭证窃取、数据窃取或设备安全风险
- 仇恨攻击、暴力威胁、欺诈及其他违反《资源审核规则》的内容

投诉原则上应包含投诉人联系方式、目标资源或版本、具体问题、权利或事实依据及真实性声明

OronBox 可以要求补充权利证明、授权链、原始发布记录、技术分析或其他与争议直接相关的材料

明显无法识别对象、没有具体理由或不属于 OronBox 控制范围的投诉，可以要求补充后再受理

投诉材料只用于核实和处置，不应无必要公开投诉人的身份和联系方式

OronBox 可以向发布者核实情况，并根据风险采取临时下架、停止下载、拒绝更新或永久移除等措施

OronBox 对自身资源目录的处理不自动改变 BandBBS、GitHub 或 AstroBox 上的内容，相关请求可能需要同时提交给对应平台

调查期间，OronBox 可以暂停审核、下载、更新和外部发布，并要求发布者在合理期限内回应

存在恶意代码、凭证泄露、现实设备安全风险、严重侵权或损害可能迅速扩大时，可以先停止下载和外部发布，再进行完整核实

通知发布者时应说明涉及的资源、主要问题、临时措施、回应期限和可提交的材料，但可以保留会帮助规避安全检测或危及投诉人的细节

发布者未回应、无法说明权利来源、伪造材料或继续扩大风险时，可以下架资源并限制发布功能

处理结果可以包括不予处理、恢复资源、要求整改、移除特定材料、下架版本、下架整个资源或限制发布权限

投诉人与发布者均可以提供新证据申请复核，外部平台的决定仍需通过其自身渠道处理

故意提交虚假材料、冒充权利人、骚扰发布者或滥用投诉渠道的，可以停止受理并按照《资源审核规则》处理

对恶意软件、凭证窃取、严重仇恨攻击、暴力威胁、大规模侵权、伪造授权、平台攻击或 Token 滥用，可以立即采取紧急措施

详细审核、处置和申诉标准见《资源审核规则》

## 10. 删除、撤销和历史记录

发布者可以申请删除草稿或下架 OronBox 资源，但这不会自动删除已经发布至米坛、GitHub 或 AstroBox 的内容

Git Commit、Pull Request、Fork、评论、平台审核和处罚记录可能无法彻底删除

已经被用户下载、缓存或转载的公开文件无法由 OronBox 全部追回

撤销 OAuth 授权只阻止未来操作，不撤销此前已经明确确认并完成的外部发布行为

## 11. 外部发布失败

外部发布可能因 OAuth 过期、权限不足、API 变化、账号限制、网络故障、格式不符或第三方审核而失败或中断

OronBox 可以在不改变发布实质的范围内自动重试，用户撤销授权、取消任务或风险处置要求停止时不再重试

OronBox 不保证米坛资源持续存在，也不保证 AstroBox Pull Request 被合并

## 12. 风险与免责声明

OronBox 审核通过不构成对资源安全性、兼容性、权利无瑕疵或适用性的明示或默示保证，也不替代用户在安装前核对设备型号、系统版本和资源来源

用户安装和使用第三方资源的风险，按照《OronBox 用户协议与免责声明》处理

## 13. 变更与终止

扩大必要许可、增加外部发布目标或扩大 OAuth 权限时，应更新本协议并重新取得必要确认

用户不同意新增的第三方发布条款时，可以停止使用对应目标，不影响其他可独立使用的 OronBox 功能

协议终止不影响终止前已经发生的发布、公开记录、权利义务和争议处理

## 14. 发布者责任

如果发布者因故意或过失违反权利保证或本协议，导致 OronBox 或其维护者承担经生效裁判或其他依法确定的直接损失，发布者应在适用法律允许的范围内承担相应责任，OronBox 应采取合理措施避免损失扩大

## 15. 法律适用与争议解决

本协议的法律适用与争议解决，按照《OronBox 用户协议与免责声明》的相关约定处理
