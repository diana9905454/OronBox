# OronBox 隐私说明

版本：1.1.0
生效日期：2026-10-19

## 1. 适用范围

本说明适用于 OronBox 客户端及项目维护者提供的官方在线服务，不适用于自行部署的 OronBox Server，也不替代 BandBBS、GitHub、Cloudflare 或其他第三方的隐私说明

## 2. 我们处理的信息

登录 BandBBS 时，官方服务会处理米坛用户 ID、用户名、头像、授权范围以及完成登录所需的 OAuth 凭证

启用米坛发布时，会另行处理发布所需的授权凭证、目标分区、资源 ID、附件和发布状态普通登录授权不等于米坛发布授权

使用 GitHub 账号发布 AstroBox 资源时，会处理 GitHub 用户 ID、用户名、授权范围、Access Token，以及完成授权所需的临时校验信息

官方服务还会处理 OronBox 会话、客户端平台和版本、IP 地址、User-Agent，以及保障登录、审核和服务安全所需的操作记录

创建资源时，会处理用户主动提交的名称、说明、图片、资源文件、设备绑定、审核记录和外部发布配置

处理权利投诉、安全事件和申诉时，可能处理投诉内容、权利证明、创作者回应、文件哈希、审核意见和与事件直接相关的证据

除法律要求或具体争议确有必要外，OronBox 在线服务不要求提供身份证号码、精确住址、生物识别、金融账户等与服务无关的信息

登录后，客户端在启动或返回前台时上报当前版本与平台，用于统计日活、月活及版本使用情况
同一账号同一天不重复计入活跃，升级后可以更新版本记录；离线记录不补传
这项统计不包含音频、健康记录、运动轨迹或设备认证密钥

## 3. 处理目的

这些信息仅用于：

- 登录和维护 OronBox 会话
- 保存、审核、展示和分发资源
- 按用户选择发布到米坛或 AstroBox
- 同步公开资源的下载副本
- 防止滥用、排查故障和处理权利投诉

OronBox 不使用这些信息投放广告、建立营销画像或出售给第三方

## 4. OAuth 与安全

BandBBS 只读 Access Token 保存在用户设备上，客户端直接使用它访问 BandBBS；其他 OAuth Token 加密保存在服务器上，不会下发到客户端OronBox 会话 Token 在数据库中仅保存不可反向还原的哈希

OAuth Token、Authorization Header、会话 Token 等敏感信息不会写入普通日志

用户可以撤销 OAuth 授权或退出 OronBox撤销后停止后续操作，但不会自动删除已经发布到第三方平台的内容和公开历史

BandBBS 登录授权、BandBBS 发布授权和 GitHub 发布授权相互独立普通 BandBBS 登录不授权创建或修改米坛资源，GitHub 授权也不代表用户已经确认某次具体仓库或 Pull Request 操作

## 5. 存储地点

官方主服务器位于中国香港，账号、OAuth 凭证、会话、草稿、资源、审核记录和文件对象在该服务器处理

资源图片由主服务器存储与分发，二进制文件由本地与 Cloudflare R2 存储，正常通过 R2 分发R2 不保存 OAuth Token、账号资料、未公开草稿或内部审计日志

用户通过官方在线服务提交的数据会在中国香港处理，公开资源副本可能经 Cloudflare 网络存储和分发

## 6. 对外提供和公开

资源发布后，名称、说明、作者名称、图片、文件、支持设备和版本信息会公开提供

用户选择米坛发布时，OronBox 会向 BandBBS 发送完成创建或更新资源所需的内容和身份信息

用户选择 AstroBox 发布时，OronBox 会向 GitHub 和 AstroBox-Repo 提交资源仓库内容、作者名称、Commit 和 Pull Request

公开资源可能被第三方下载、转载或缓存，OronBox 无法删除已经由其他主体保存的全部副本

发生侵权、安全或平台滥用事件时，OronBox 可以按最小必要原则向第三方平台、权利人或相关机构提供资源、外部标识、文件哈希、发布时间和审核记录

IP、User-Agent、设备和会话信息仅在处理账号安全、自动化滥用、封禁规避或其他严重事件确有必要时提供

公开资源副本的存储和网络分发由 Cloudflare, Inc. 提供

## 7. 保存和删除

OAuth 临时校验信息在数分钟内失效；OronBox 会话 Access Token 有效期为 15 分钟，Refresh Token 有效期为 30 天，会话轮换、撤销或账号状态变化后可以提前失效

BandBBS 和 GitHub OAuth 凭证保存至用户撤销授权、解绑账号或不再为相关功能所需为止

未提交草稿在最后编辑后保留 180 天；用户主动删除的草稿立即从活跃数据库删除

普通服务日志保留 30 天，安全审计记录保留 180 天，投诉、举报和申诉材料在事件结束后保留 1 年

公开资源、版本、图片和公开元数据在公开期间持续保存，已下架资源的必要审核记录在下架后保留 1 年

撤销或解绑 OAuth 授权后，凭证立即从活跃数据库删除；账号注销后，账号资料在 7 天内删除或匿名化

存在未结束投诉、安全事件或法定保存义务时，相关数据会暂停删除，仅保留处理事件所需的最小范围

## 8. 用户请求

用户可以请求查询或更正账号资料、撤销授权、删除未公开草稿，或申请删除不再需要保存的个人信息

已发布至 BandBBS、GitHub 或 AstroBox 的内容需要按照对应平台的机制另行处理

账号注销后，有效会话失效并停止后续 OAuth 操作，但处理安全、投诉和争议所必需的最小记录可以继续保存

可以通过 App 内的意见反馈入口或联系邮箱提交上述请求OronBox 在完成必要的身份核验后 15 个工作日内答复，情况复杂需要延长时会说明原因和预计时限

## 9. 自行部署

自行部署者独立控制其服务器中的数据，应自行说明运营身份、存储地点、日志、OAuth 配置和数据处理方式

OronBox 项目维护者无法访问或控制自行部署实例中的数据

## 10. 信息安全

官方服务会采取与项目规模和数据风险相称的措施，包括 HTTPS、短期登录票据、会话轮换、Token 加密、最小权限、访问控制和日志脱敏

发生可能影响用户权益的安全事件时，维护者会尽快控制风险、撤销受影响凭证、保存必要证据，并在合理可行且依法需要时通知相关用户或机构

互联网服务不存在绝对安全，用户也应保护自己的设备、账号和授权凭证

## 11. 未成年人

OronBox 面向具有相应理解和操作能力的穿戴设备用户未成年人应在监护人指导下使用账号授权、资源发布和可能影响设备的功能

## 12. 变更与联系

新增个人信息用途、扩大 OAuth 权限、扩大第三方提供范围或改变主要存储地点时，会更新本说明并在必要时重新取得确认

与官方在线服务有关的法律适用与争议解决按照《用户协议与免责声明》处理

## 13. 客户端本地数据与备份

设备配对信息、设备认证密钥和账号凭证用于连接设备或访问用户选择的平台，客户端通过系统提供的安全存储能力保存敏感凭证
健康记录、运动轨迹、设备截图、插件数据与 ZeppOS 应用数据保存在本机，不因使用本地功能而自动上传至 OronBox 在线服务
Web 版使用浏览器提供的本地存储，清理站点数据或浏览器回收空间可能移除这些数据

应用数据管理可以查看占用、清理可回收缓存并导出备份
备份可能含有健康记录及用户主动选择的其他本地数据，请自行选择可信的保存位置，不要公开分享
设备配对与认证密钥、小米账号及登录会话仅在用户主动勾选后加入备份，默认不选中
此类备份文件未加密，请妥善保管，不要公开分享
应用备份不包含 OronBox、米坛账号凭证或插件权限授权，导入备份不代表重新授权插件
用户主动导出的音频、截图、日志和备份由用户选择的保存位置或接收方管理

## 14. 语音识别

语音助手实验功能接收用户主动触发的穿戴设备音频
选择本地识别时，音频在当前设备上处理；首次使用需主动下载模型及所需运行库，模型和运行库托管方会接收下载请求和网络连接信息
选择微信或豆包输入法在线测试时，经确认后音频会直接发送至所选第三方识别服务，对方会处理音频、匿名连接标识及网络连接信息并返回文字
这些测试服务不由 OronBox 运营，其可用性、使用限制和数据处理规则由第三方决定
未选择在线识别时不会自动改用在线服务，某一服务失败也不会自动发送给另一服务

客户端不在普通日志中记录音频、识别文字、设备认证密钥或匿名识别凭证
实验页中的录音和识别结果用于当前会话，只有用户主动导出才保存到其选择的位置
停止语音实验或退出页面会结束识别连接，本地模型可在应用内删除

## 15. 权限与空间查询

相机用于扫描二维码，用户选择的图片可用于识别二维码
定位权限用于用户启用的位置相关功能
启用手机辅助定位后，运动准备和进行期间会将手机位置通过设备连接发送给穿戴设备
在后台接收设备运动请求需要单独授予相关权限，运动定位期间会显示系统通知或定位指示
此功能不保存手机轨迹，也不向 OronBox 服务端上传位置
蓝牙与附近设备权限用于发现和连接穿戴设备
权限可在系统设置中撤销，相关功能可能因此无法使用
下载模型前查询可用存储空间，用于避免空间不足，空间查询结果不随活跃统计上传
