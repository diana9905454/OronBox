# OronBox 资源发布与审核规则

版本：1.0.0
生效日期：2026-07-19
最近更新：2026-07-19

本规则适用于 OronBox 自有资源目录，以及通过 OronBox 提交至米坛、AstroBox-Repo 的资源内容标准适用于全部 OronBox 资源

## 第一章 适用对象

本规则适用于：

- 资源名称、简介、更新日志和标签；
- 应用、小程序、表盘及其他安装文件；
- 图标、封面、截图、预览图和音频；
- manifest、README、许可证和第三方组件；
- 设备支持声明和文件绑定；
- 评论、申诉、权利证明和审核沟通；
- 米坛资源、GitHub 仓库、commit、Pull Request 及相关外部发布内容

## 第二章 基础提交要求

### 2.1 平台与类型

1. 资源实际平台和类型必须与创建时选择一致
2. 不得通过修改扩展名、包头、manifest 或元数据伪装资源类型
3. 服务端识别结果不一致时，文件将被拒绝

### 2.2 图片

1. 至少提供一张预览图
2. 图片应与资源实际界面或内容相关，不得使用无关、虚假或误导图片
3. OronBox 会保持比例、限制宽高不超过 1500px，并转换为 WebP
4. 发布 AstroBox 时，创作者应另行提供方形 icon 和 3:2 cover
5. 不得在图片中盗用商标、作品、人物肖像或其他受保护内容

### 2.3 资源文件与设备

1. 至少提供一个有效资源文件
2. 每个文件至少绑定一个支持设备
3. 同一文件可以绑定多个设备；同一版本可以包含多个文件
4. 支持设备声明应有合理测试或适配依据
5. 不得故意将不兼容设备标记为支持

### 2.4 元数据

名称、作者、版本、包 ID、功能、收费属性、许可证、更新日志和支持设备应真实准确，不得：

- 伪造官方、原作者或团队身份；
- 隐瞒关键限制、权限、收费和联网行为；
- 使用明显误导、夸大或虚假描述；
- 使用与其他资源高度混淆的名称、图标或封面；
- 通过堆砌标签、关键词或重复资源操纵展示

## 第三章 禁止内容与行为

### 3.1 违法和严重不当内容

不得上传、发布、传播或为下列行为提供便利：

1. 违反适用法律法规、监管要求或公序良俗的内容；
2. 危害公共安全、破坏社会秩序或煽动实施违法行为的内容；
3. 淫秽色情、强烈性暗示、性剥削或不适宜未成年人接触的内容；
4. 过度血腥、虐待、暴力威胁、鼓励自残或鼓励伤害他人的内容；
5. 侮辱、诽谤、骚扰、威胁、跟踪、人肉搜索或恶意曝光个人信息；
6. 欺诈、钓鱼、虚构事实、隐瞒关键事实或诱导用户作出错误决定；
7. 未经许可的广告、垃圾信息、恶意导流、刷量或重复铺量；
8. 具有明显宗教斗争、政治动员、煽动群体对立，或可能使 OronBox 及相关平台卷入重大政治和公共事件的内容；
9. 违反适用经济制裁、出口管制或受限用途规定的功能或服务；
10. 其他米坛、AstroBox 或适用法律明确禁止且与资源发布有关的内容

### 3.2 身份攻击、歧视与仇恨

不得基于个人或群体的下列身份特征实施攻击：

- 种族、肤色或民族；
- 国籍、族群或地域出身；
- 宗教或信仰；
- 性别、性别认同或性别表达；
- 性取向；
- 年龄；
- 残疾、疾病状况或其他类似身份特征

禁止行为包括：

1. 使用侮辱性、贬低性或去人化称呼；
2. 宣扬某类群体天生低劣、危险、肮脏或不应享有平等权利；
3. 鼓励排斥、隔离、驱逐、歧视或剥夺权利；
4. 威胁、赞美、合理化或煽动针对相关群体的暴力和伤害；
5. 通过资源名称、功能、图片、音频、文案、彩蛋或更新内容实施上述行为；
6. 以"玩笑""反串""抽象""测试"或"作者观点"为由掩饰明显的身份攻击

对历史事件、政策、宗教观念、文化或社会议题进行正常讨论、批评、讽刺、研究或艺术表达，不因涉及相关身份而当然违规，判断重点在于是否针对身份本身实施侮辱、歧视、仇恨或煽动伤害

### 3.3 知识产权和冒充

禁止：

1. 未经授权复制、修改、重新打包或发布他人资源；
2. 盗用代码、图片、字体、音乐、图标、封面、截图、商标或文案；
3. 违反开源许可证、隐瞒来源或删除必要署名；
4. 冒充官方、厂商、组织、团队或其他创作者；
5. 伪造许可证、授权书、购买凭证、源文件或开发记录；
6. 将他人资源作轻微修改后冒充原创；
7. 提供专门用于绕过正版授权、付费、签名、访问控制或技术保护措施的内容，法律明确允许的兼容研究除外；
8. 提交包含 AI 生成内容的资源时，创作者应当声明，并对 AI 生成部分的权利瑕疵、侵权风险及合规性依法承担相应责任

### 3.4 安全与恶意行为

禁止资源包含、执行或协助：

1. 病毒、木马、勒索软件、后门、远程控制和破坏性代码；
2. 窃取账号、密码、Cookie、Token、短信、联系人或其他数据；
3. 未经用户充分知情同意秘密收集、上传或共享数据；
4. 利用系统、设备、BandBBS、GitHub、AstroBox 或其他服务漏洞；
5. 绕过权限、审核、签名、收费、封禁、速率限制或访问控制；
6. 伪造请求、滥用接口、发起拒绝服务、扫描或攻击；
7. 下载和执行未披露的远程代码；
8. 欺骗用户授予与功能无关的高风险权限；
9. 将恶意载荷拆分、加密或隐藏以规避分析；
10. 为盗号、欺诈、侵权、仇恨攻击或平台滥用提供实质性工具和便利

### 3.5 隐私和数据处理

资源收集或处理用户数据时，应：

1. 在说明中清晰披露数据种类、目的、方式和去向；
2. 仅申请与功能必要相称的权限；
3. 在依法需要时取得用户同意；
4. 提供停止、删除或撤回机制；
5. 采取合理安全措施；
6. 不得将数据用于未披露的广告、营销、画像或出售；
7. 不得要求用户提供与功能无关的敏感数据；
8. 不得将 BandBBS、GitHub 或 OronBox 数据用于建立未经许可的关系链

### 3.6 不得提供便利

创作者不得仅以"资源本身不直接实施"为由规避责任资源、插件、脚本、教程、接口或服务不得为他人的违法、侵权、歧视、仇恨、欺诈、数据窃取、账号攻击或平台滥用提供实质性便利

## 第四章 质量和兼容性

1. 资源应具备与描述相符的基本功能
2. 不得提交明显无法运行、空壳、损坏或仅用于占位的资源
3. 已知会导致设备变砖、数据丢失、异常耗电、循环崩溃或其他严重风险时，应在显著位置说明；风险无法合理控制时不得发布
4. 更新不得在未说明的情况下移除核心功能、加入高风险权限或改变收费方式
5. 付费属性、授权方式和使用限制必须准确
6. AstroBox 专用元数据应符合 AstroBox-Repo 届时有效的结构和字段要求

## 第五章 审核流程

### 5.1 状态

资源版本涉及三类状态：

- **修订状态**：草稿、待审核、已通过、已拒绝提交新版本后，旧版本标记为已取代
- **管理状态**：正常、已下架、已冻结已下架和已冻结的资源停止展示和下载
- **发布状态**（外部发布）：等待、处理中、外部审核、已发布、失败、已取消

### 5.2 审核内容

OronBox 可以检查：

- 平台、类型、格式和包 ID；
- 版本和设备绑定；
- 图片和描述真实性；
- 恶意代码和高风险行为；
- 第三方组件和许可证；
- 身份、商标和权利争议；
- 内容标准；
- 外部平台格式要求

### 5.3 审核结果

1. **批准**：版本进入 OronBox 公开目录，并触发用户选择的外部发布任务
2. **需要修改**：列出需要修正的问题，版本不公开
3. **拒绝**：说明主要原因，创作者可按规则修改后重提或申诉
4. **紧急暂停/下架**：适用于公开后发现的严重风险

评论先经自动筛查再由人工复核，重大账号处罚会经人工复核

## 第六章 处置和处罚

本章所列措施与《OronBox 用户协议与免责声明》第 6 条设定的管理权限互为补充，账号级的停用和封禁等措施按照相关协议执行

### 6.1 资源版本级

- 提醒或警告；
- 要求限期修改；
- 拒绝版本；
- 暂停审核；
- 暂停展示或下载；
- 下架或删除特定版本

### 6.2 资源主体级

- 下架整个资源；
- 阻止提交新版本；
- 撤销当前公开版本；
- 停止 CDN 分发；
- 取消或暂停外部同步

### 6.3 创作者功能级

- 暂停创建资源；
- 暂停提交或更新；
- 要求重新验证身份或权利；
- 暂停米坛发布；
- 暂停用户 GitHub 发布；
- 暂停或永久撤销创作者资格

### 6.4 账号级

- 限制部分功能；
- 强制退出全部会话；
- 临时停用账号；
- 长期或永久封禁；
- 对用于规避处罚的关联账号采取措施

### 6.5 外部平台协同

- 取消尚未执行的发布任务；
- 停止自动重试；
- 向米坛申请处理相关资源或账号；
- 向 AstroBox-Repo 维护者报告资源、仓库或 Pull Request；
- 向 GitHub 报告滥用、安全或侵权行为；
- 根据外部平台决定复核 OronBox 内的资源和账号

## 第七章 处罚判断

OronBox 将综合考虑：

1. 违规性质和现实危害；
2. 是否故意、明知或以规避为目的；
3. 影响范围、下载量和持续时间；
4. 是否首次违规；
5. 是否主动停止、修复和披露；
6. 是否配合审核、投诉和安全响应；
7. 是否伪造材料或隐瞒事实；
8. 是否重复违规或规避处罚；
9. 是否危及账号、设备、数据或平台安全；
10. 第三方平台、权利人或主管机关的处理意见

不实行机械的"首次必警告"规则恶意软件、凭证窃取、严重仇恨和暴力、重大侵权、欺诈、Token 滥用和平台攻击可以首次即永久处置

## 第八章 紧急措施

存在明显违法、恶意代码、账号或数据安全风险、严重侵权、严重身份攻击、暴力威胁、平台攻击或其他需要立即控制风险的情形时，OronBox 可以先行：

- 停止下载；
- 下架资源；
- 中止审核；
- 终止外部发布任务；
- 撤销会话；
- 临时停用账号；
- 保存必要证据；
- 向相关平台和安全团队报告

OronBox 将在不妨碍调查和风险控制的前提下，于合理期限内通知用户

## 第九章 封禁规避

禁止通过下列方式规避处置：

- 更换或重新注册 BandBBS 账号；
- 更换 GitHub 账号；
- 借用他人账号；
- 修改资源 ID、包 ID、文件哈希或名称后重复提交；
- 使用其他接口回流至官方服务；
- 其他实质上继续实施被限制行为的方式

## 第十章 通知、整改和申诉

1. 通知通常包括资源或账号、规则类别、措施、开始时间、期限和申诉入口
2. 为保护检测机制、投诉人、安全调查或防止规避，OronBox 可以不披露全部证据和风控细节
3. 创作者可以在 15 个自然日内提交事实说明、权利证明、技术分析、修复版本、账号被盗证明或其他新证据确因不可抗力或其他正当理由无法按时提交的，可在期限届满前申请延长，OronBox 将视情况决定是否准许
4. 复核结果可以是维持、减轻、解除、要求整改后恢复或加重处罚
5. 恢复资源不当然恢复全部外部发布资格
6. 外部平台的决定应通过该平台渠道申诉，OronBox 申诉不能替代米坛、GitHub 或 AstroBox 的程序

## 第十一章 规则变更

1. OronBox 可根据法律、包格式、安全风险、设备平台和第三方规则更新本规则
2. 重大内容标准或处罚规则变化将通知创作者
3. 已发布资源可能需要适配新标准；存在重大安全风险时，新规则可立即适用
4. 对于非紧急且不涉及安全的重大规则变更，OronBox 将向创作者提供不少于 15 日的合理过渡期，过渡期结束后，不符合新标准的资源可能被限制公开分发
